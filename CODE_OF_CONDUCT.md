# Code Of Conduct

This project follows an evidence-led conduct standard.

Expected behavior:

- respect contributors and reviewers
- argue from artifacts, not status
- preserve negative and inconclusive results
- keep claims inside their proved scope

Unacceptable behavior:

- harassment or intimidation
- dismissing contradictory evidence without counter-evidence
- inflating claims beyond the proof surface
- publishing private information without permission

Report conduct issues to `architects@zer0pa.ai`.
