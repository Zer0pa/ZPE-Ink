# Public Audit Limits

This repo is currently a private staging surface, not a public release packet.

What this repo can establish now:

- package boundary and layout are clean
- the core Python codec exists and is runnable
- curated proof anchors from the Wave-1 bundle are preserved
- the quality-vs-handoff contradiction is explicit

What this repo does not establish now:

- a greenlit release verdict
- cold-clone verification on a clean outsider machine
- broader performance authority
- external corpus reruns from the staged repo alone

The raw Wave-1 warehouse remains outside the repo boundary in the outer workspace. This repo intentionally carries only a curated proof subset.
