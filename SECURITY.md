# Security Policy

Report security issues privately to `architects@zer0pa.ai`.

Use this channel for:

- committed secrets or credentials
- dependency vulnerabilities that materially affect this repo
- code paths that allow arbitrary code execution, privilege escalation, or data exfiltration
- CI workflow weaknesses that could compromise staged artifacts

Do not use this channel for:

- normal codec bugs
- falsification findings
- evidence disputes about documented claims

Those belong in standard issues with artifact-backed reproduction.
