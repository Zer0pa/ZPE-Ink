Support routing for the ZPE-Ink private staging surface.

<p>
  <img src="../.github/assets/readme/section-bars/where-to-go.svg" alt="WHERE TO GO" width="100%">
</p>

- Use GitHub issues for reproducible bugs or documentation defects.
- Use evidence dispute issues for contradictory proof or claim surfaces.
- Use `architects@zer0pa.ai` for security reports.

<p>
  <img src="../.github/assets/readme/section-bars/what-gets-a-fast-response.svg" alt="WHAT GETS A FAST RESPONSE" width="100%">
</p>

- Reproducible bugs with exact commands and outputs.
- Evidence disputes that include the conflicting artifacts.
- Security reports that include concrete impact scope.

<p>
  <img src="../.github/assets/readme/section-bars/what-does-not-get-a-response-here.svg" alt="WHAT DOES NOT GET A RESPONSE HERE" width="100%">
</p>

- Requests for public release before the release surface is pass.
- Speculative performance claims without artifacts.
- Non-reproducible observations without command output.

<p>
  <img src="../.github/assets/readme/section-bars/response-expectations.svg" alt="RESPONSE EXPECTATIONS" width="100%">
</p>

This repo is private staging only. There is no public support SLA. Evidence-first issues receive priority.
