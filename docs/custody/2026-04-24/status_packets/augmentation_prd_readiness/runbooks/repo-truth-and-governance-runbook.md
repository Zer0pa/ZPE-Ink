## Output Artifacts

- repo truth matrix
- reconciliation note
- contradiction ledger
- governance compliance list
- repo-front-door change queue for later GitHub work

## Acceptance Gate

- Archived `NO-GO` remains sovereign unless explicitly superseded by a newer evidence-backed artifact.
- Every contradiction is classified as one of:
  - stale archived assumption
  - stale live doc claim
  - live repo truth
  - unresolved blocker
- No front-door or market wording remains broader than the governing authority packet.
- Repo playbook and ethos constraints are translated into explicit later GitHub actions instead of vague cleanup language.

## Failure Mode

- README or market surface still contradicts the governing artifact.
- Legal/package metadata remain inconsistent.
- The plan treats parity evidence or doc polish as a wedge-upgrade proxy.
- Roadmap restructuring begins before user approval.
