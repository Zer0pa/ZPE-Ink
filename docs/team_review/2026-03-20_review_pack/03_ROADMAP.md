# Roadmap: ZPE-Digital-Ink

## Overview

This roadmap treats ZPE-Digital-Ink as a proof-first utility-kernel program, not a product-story blender. The first phase exhausts what can be done locally on the current MacBook M1 Air with free downloadable resources only; later phases absorb the assets that genuinely require gated SDKs, hardware, broader corpus access, or a stronger runtime change than the current transport core can honestly sustain.

## Phases

- [ ] **Phase 1: Local Authority Rerun and Kernel Uplift** - Exhaust the Mac-local, free-resource-only lane: official comparator research, public-corpus ingestion, local uplift or narrowing, and gate reruns.
- [ ] **Phase 2: External Comparator and Hard-Corpus Closure** - Use the assets that Phase 1 is not allowed to assume: larger or gated corpora, platform capture surfaces, and external comparator closure.
- [ ] **Phase 3: Primitive or Hybrid Runtime Challenger** - Decide whether a true primitive/hybrid runtime deserves promotion beyond explicit challenger status.
- [ ] **Phase 4: Wedge Proof and Enterprise Interoperability** - Prove one commercialization wedge without letting it rewrite the science metric.
- [ ] **Phase 5: Release Truth and Enterprise Readiness** - Resolve the PASS-versus-NO-GO contradiction and decide whether any enterprise-readiness claim survives.

## Phase Details

### Phase 1: Local Authority Rerun and Kernel Uplift

**Goal:** Exhaust the local M1 Air lane without cheating: refresh official comparator context, rerun the frozen pack, add a public free-corpus lane that fits the disk budget, and execute one deterministic uplift or narrowing loop.
**Depends on:** Nothing (first phase)
**Requirements:** [RESR-01, RESR-02, DATA-01, DATA-02, ENG-01, ENG-02, ENG-03, VALD-01, VALD-02, VALD-03, EXEC-01]
**Contract Coverage:**
- Advances: `claim-local-authority`, `claim-local-kernel-uplift`
- Deliverables: benchmark pack, market-gap report, kernel change or challenger branch, state summary
- Anchor coverage: PRD, metric/runtime/wedge freezes, Wave-1 proof anchors, release contradiction report, official comparator sources
- Forbidden proxies: structured-tier wins narrated as universal authority; adapter breadth treated as enterprise proof; Phase 1 external-resource cheating
**Success Criteria** (what must be TRUE):

1. Official comparator surfaces are mapped from primary sources, with local/free versus gated/external boundaries stated explicitly.
2. The frozen local benchmark pack is rerun on the current machine with artifact capture and no hidden byte-accounting drift.
3. At least one free public corpus subset is evaluated locally, or the inability to do so is evidenced as a real blocker rather than silently replaced with proxies.
4. One deterministic local-only uplift, challenger evaluation, or evidence-backed narrowing step is executed against the transport gates.
5. The phase summary names unresolved hard-corpus, runtime-identity, and release contradictions instead of averaging them away.
   **Plans:** 3 plans

Plans:

- [ ] 01-01: Map official comparator surfaces and the local execution envelope
- [ ] 01-02: Add the free-public-corpus lane and implement the local uplift or challenger evaluation
- [ ] 01-03: Rerun gates, compare outcomes, and publish the honest Phase 1 summary
